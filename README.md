# Araz Flow 2.0.0 — Build 004

Build 004 مشکل از بین رفتن داده هنگام بستن سریع صفحه را رفع می‌کند.

## تغییر اصلی
- نوشتن همگام و فوری در localStorage پیش از شروع ذخیره‌سازی IndexedDB
- نوشتن اضطراری همگام هنگام مخفی‌شدن یا بسته‌شدن صفحه
- حفظ IndexedDB، Snapshot، Backup و تمام قابلیت‌های Build 002

## تست پیشنهادی
1. یک پروژه آزمایشی ثبت کن.
2. بلافاصله صفحه را ببند.
3. دوباره همان آدرس را باز کن.
4. پروژه باید باقی مانده باشد.


برای تست حتماً آدرس را با ?v=004 باز کنید.
