# Araz Flow 2.0.0 — Build 002

نسخه آزمایشی پایدارسازی دیتابیس برای میزبانی روی GitHub Pages.

## روش انتشار
تمام فایل‌های این پوشه باید در ریشه مخزن `araz-flow` جایگزین شوند.

## آزمایش ضروری
1. برنامه را باز کنید و دکمه «آزمایش ذخیره‌سازی» را بزنید.
2. یک پروژه آزمایشی ثبت کنید.
3. صفحه را کاملاً ببندید و دوباره باز کنید.
4. فایل `index.html` نسخه جدید را روی همان آدرس جایگزین کنید و باقی ماندن پروژه را بررسی کنید.
5. یک فایل پشتیبان بگیرید و بازیابی آن را نیز آزمایش کنید.
